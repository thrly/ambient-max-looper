# thrly's Multichannel Ambient Looper
an multichannel ambient performance looper, built on YouTube in [Max MSP](https://cycling74.com/downloads)

Watch the video here:

[![Building an Ambient Looper in Max](https://img.youtube.com/vi/-BbwPgylmjA/0.jpg)](https://www.youtube.com/watch?v=-BbwPgylmjA)

## How to use
- [Watch the video](https://youtu.be/-BbwPgylmjA)
- Try and build it yourself.
- Download this project folder.
- Open the .maxproj file in Max 9 (or above).

I hope this is helpful to you. Feel free to hack it up, turn it into your own thing and make some noise!
